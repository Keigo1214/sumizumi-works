# 案件別 掲載ルール台帳

CLAUDE.md ルール10：**記事を書く前にこの台帳を確認する。** 違反は成果全否認・提携解除になりうる。
列は設計書 `docs/article-template.md` §1-8（リンク）・§1-10（推薦のルール）・§7 工程2 に対応する。

- 1行 = 1案件。案件IDは front matter の `programs`・`data/asp-programs.csv` の `program_id`・`data/cta_patterns.yaml` のキーと同じにする（lint は `programs` が `asp-programs.csv` にあるかを確かめる）
- 「可／不可／条件付き／未確認」で書き、条件付きなら条件を、**根拠（掲載ルールのURLや画面名）と確認日**を必ず書く
- 未確認の項目がある案件は、記事に使う前に確認する
- 掲載ルールは変わる。提携時と、ASPからの通知があったときに見直す

## 列の説明

| 列 | 書くこと | 設計書 |
|---|---|---|
| 直接リンクの可否 | 広告主サイトへの通常リンク（P7の参考資料・提携前の公式リンク）を置いてよいか | §1-8 |
| リンクコードへの rel 付与 | ASPのリンクコードに `rel="sponsored"` を加えてよいか。**不可で、Cocoonのボタン等の外側でも付けられないなら、その案件は使わない** | §1-8・§11-2 |
| 計測用の画像タグの扱い | インプレッション計測用の画像タグを残す必要があるか、改変してよいか | §1-8・§6 |
| 順位付けの禁止 | 順位付けの禁止の有無。条件別の推薦（「◯◯なら X」）に当たるかが分かれば書く | §1-10・§11-5 |
| 他社の併記・他社へのリンク | 他社製品の併記・他社へのリンクの可否。**併記を禁じていて、非提携の最適製品の推薦と両立しない場合は、その記事ではこの案件のCTAを置かない** | §1-10 |
| 表現の禁止事項 | 使ってはいけない表現・必須の表記 | §1-6 |
