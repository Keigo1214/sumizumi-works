# Phase 0-B WordPress構築 手順書

前提: xserver契約済み（別案件と同居）。この手順で**アフィリサイトを独立サイトとして**構築する。

## 設計の原則（売却性のため守る）

1. **別案件と混在させない** — サブディレクトリに相乗りさせず、独立ドメイン＋独立WordPressにする。売却時に丸ごと切り出せる状態を保つ
2. **ドメインは独立取得**（xserverの永久無料ドメインは使わない）— 契約に紐づかず、認証コードで移管できるものにする
3. **ドメインは中立・ブランド型**（ジャンル一致名にしない）— Phase 1/2のジャンル変更・業種拡張に耐える
4. **有料テーマの単一ライセンスに依存しない** — 売却時に買い手がそのまま使えないと価値が落ちる。GPLの無料テーマを基本にする

## STEP 1: ドメインをxserverに接続

1. xserverサーバーパネル →「ドメイン設定」→「ドメイン設定追加」→ 取得したドメインを入力
2. 「無料独自SSLを利用する」に**チェック**、「高速化・アクセス数拡張機能」も有効のまま追加
3. ドメイン側（レジストラ）のネームサーバーをxserverのもの（ns1〜ns5.xserver.jp）に変更
4. 反映まで数時間〜最大48時間。`https://ドメイン/` で「無効なURL」等が出れば反映待ち

> **注意**: SSL証明書の発行に時間がかかることがある。`https://` でアクセスできるようになってから次へ。

---

## STEP 2: WordPressをインストール

1. サーバーパネル →「WordPress簡単インストール」→ 対象ドメインを選択
2. 設定:
   - サイトURL: `https://ドメイン/`（wwwなし・サブディレクトリなしを推奨）
   - ブログ名: 仮でよい（後で変更可。サイト名はPhase 2で確定）
   - ユーザー名: **`admin` は使わない**。推測されにくい名前に
   - パスワード: 強固なもの（パスワードマネージャで生成）
   - メールアドレス: STEP 0で用意したもの
   - キャッシュ自動削除: ON / データベース: 自動生成
3. インストール後、管理画面URL（`https://ドメイン/wp-admin/`）をブックマーク

## STEP 3: WordPress初期設定（記事を書く前に必ず）

### 3-1. パーマリンク（最重要・後から変えると全URL変わる）
設定 → パーマリンク → **「投稿名」** を選択（`https://ドメイン/記事スラッグ/`）。
記事公開後に変更するとURLが全部変わり被リンク・評価を失うので、**最初に確定させる**。

### 3-2. インデックス制御（構築中は止める）
設定 → 表示設定 → **「検索エンジicンがサイトをインデックスしないようにする」に一時的にチェック**。
> ⚠️ **公開準備が整ったら必ずチェックを外す。** 外し忘れるとサイトが永久に検索に出ない。ローンチ前チェックリストに入れること。

### 3-3. 一般設定
- サイトのタイトル / キャッチフレーズ（仮）
- WordPressアドレス・サイトアドレス: `https://` で統一
- タイムゾーン: 東京 / 言語: 日本語 / 日付形式: 任意

### 3-4. ディスカッション（コメント）
比較・情報サイトではコメントはスパムの温床になりやすい。
設定 → ディスカッション → 「新しい投稿へのコメントを許可」を**オフ**（必要な記事だけ個別にオンにする運用）。

### 3-5. 不要物の削除
- サンプル投稿「Hello World」、固定ページ「サンプルページ」を削除
- 不要な初期プラグイン（Hello Dolly等）を削除
- 使わないテーマを削除（有効テーマとその子テーマ以外）

## STEP 4: テーマ

### 推奨: Cocoon（無料・GPL・国産・アフィリSEO向き）
理由: 完全無料でGPL（売却時に買い手がそのまま使える）、比較ボックス・CTAボタン・ランキング等アフィリ向け機能が標準装備、表示速度対策済み、構造化データ対応。

- 有料の代替（SWELL等）は高速で使いやすいが、**単一購入者ライセンスのため売却時に買い手が別途購入し直す必要があり、売却性で不利**。初期はCocoonで十分。

### 手順
1. Cocoon公式から親テーマ・子テーマをダウンロード
2. 外観 → テーマ → 新規追加 → アップロード（親→子の順）
3. **子テーマを有効化**（`ad-disclosure.md` のPHPは子テーマの `functions.php` に入れる。親テーマに書くと更新で消える）
