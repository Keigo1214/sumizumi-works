# data/sources/ — 出典の一覧と手動確認の記録

記事ごとに `data/sources/{slug}.md` を1つ作る（`{slug}` は正本 `articles/{slug}.md` の front matter の `slug`）。
雛形は `_template.md`。役割は2つ。

1. **出典の一覧**（設計書 §7 工程3「素材収集」の成果物）。書式は自由
2. **手動確認の記録**（設計書 §8 T2・T7）。**書式が決まっている**（`tools/factcheck.py` が読む）

## 手動確認の記録の書式

**見出しの文字と列の名前は変えない。**

```markdown
## 手動確認の記録

| URL | 数値 | 種類 | 確認者 | 確認日 | 理由 | ページのハッシュ | メモ |
|---|---|---|---|---|---|---|---|
| https://x.example.com/pricing | 300円 | 不一致 | 実行者の名前 | 2026-09-27 | JavaScript描画 | | 料金表で確認 |
| https://law.example.go.jp/xxx | - | 不一致 | 実行者の名前 | 2026-09-27 | robots.txt 拒否 | | 数値のない出典 |
| https://y.example.com/price | 0円 | 偶然の一致 | factcheck_session | 2026-09-27 | 偶然の一致の確認 | 3f9a0c1d2e4b5a67 | 初期費用の欄 |
```

| 列 | 必須 | 書くこと |
|---|---|---|
| URL | 必須 | 正本の出典マーカーに書いたURLと**同じ文字列**（末尾の `/` の有無は区別しない） |
| 数値 | 必須 | **正本に書いた表記のまま**（「300円」）。1行に1つ。数値のない出典のURLそのものを確認した場合は `-` |
| 種類 | 任意 | `不一致`（既定。不一致・取得失敗の確認）か `偶然の一致`（照合のレポートの「偶然の一致の可能性」の確認） |
| 確認者 | 必須 | 下の「種類ごとの規則」 |
| 確認日 | 必須 | `YYYY-MM-DD` |
| 理由 | **必須** | robots.txt 拒否 / JavaScript描画 / リダイレクト / 偶然の一致の確認 など |
| ページのハッシュ | 種類が偶然の一致なら必須 | 照合のレポートの「偶然の一致の可能性」に出る、出典ページの本文のハッシュ（16文字） |
| メモ | 任意 | ページのどこで確認したか |

## 種類ごとの規則

| 種類 | 書ける人（確認者） | 有効な間 | 外すもの |
|---|---|---|---|
| 不一致 | `tools/config.yaml` の `factcheck.manual_check_allowed_checkers` の名前だけ（**実行者**。既定は空なので、実行者が自分の名前を入れる） | 確認日から90日（`manual_check_valid_days`） | 数値が見つからない・取得できない・本文を抽出できない・リダイレクト（そのマーカーの全数値に記録があるときだけ）、偶然の一致の候補 |
| 偶然の一致 | 上の名前か、`factcheck.manual_check_session_checkers` の名前（既定 `factcheck_session`。**別セッションのファクトチェックが書ける**） | **出典ページの本文のハッシュが変わるまで**（日数の期限はない） | 偶然の一致の候補だけ |

- 「Claude」「AI」などを**語として**含む名前は、許可リストにあっても無効（`manual_check_denied_checkers`。2文字以下の語は大文字小文字を区別するので「Ai」という名前の人は拒否しない）
- **記事側の数値が変わると記録は効かなくなる**（数値の値と単位で照合するため）。報告に戻るので、確認し直して新しい行を書く。古い行はレポートの「使われなかった手動確認の記録」に出るので消す
- 確認日が未来の日付・必須の列が空・確認者が書けない人・数値が読み取れない・偶然の一致なのにページのハッシュがない行は無効（レポートの「書式の警告」に出る）
- 記録で報告から外した件数は、`factcheck.py` のレポートの冒頭に出る。公開前には `publish_prep.py` の関門の要約（`build/{slug}/gate-summary.md`）に記録の一覧が出るので、実行者が中身を確かめる
- `{slug}` は英小文字・数字・ハイフンだけ（`../` などは読まない）
