# 広告表示（ステマ規制対応）

**このサイトで最も重要な法務項目。** 800〜1,200記事を書いてから対応すると全記事改修になるため、テンプレートの共通コンポーネントとして最初に実装する。

---

## 1. 規制の構造を正確に理解する

2023年10月1日施行のステルスマーケティング規制（景品表示法第5条第3号の指定告示）について、**誤解されやすい点**を先に整理する。

| 論点 | 正確な理解 |
|---|---|
| 誰が規制対象か | **商品・サービスを供給する事業者（広告主）**。アフィリエイター・インフルエンサー等の第三者は、この規制の**直接の対象ではない** |
| ではアフィリエイターは無関係か | **違う。** 広告主が責任を負う構造だからこそ、広告主・ASPは表示不備のあるアフィリエイターを**提携解除・成果全否認**で切る。事業の根幹が止まるリスクは実在する |
| 何をすれば良いか | 一般消費者が**事業者の表示であると判別できる**ようにする。表示の有無だけでなく**明瞭性**が問われる |

> **結論：法的責任の所在がどこであれ、実務上は全記事に明瞭な広告表示を出す以外の選択肢はない。**

---

## 2. 表示の文言

### 採用する文言

```
本記事には広告（アフィリエイトリンク）が含まれます。
```

「PR」ラベルと併記する。

### 使用可能とされる語

「広告」「宣伝」「プロモーション」「PR」など、一般消費者が広告であると認識できる語。

### 避けるべき表現

- 「アフィリエイトリンクを利用しています」**だけ** — 「アフィリエイト」という語を一般消費者が理解できるとは限らない
- 「一部プロモーションを含みます」のような曖昧な限定 — どこが広告か不明瞭
- 英語のみ（"Sponsored" 単独など）
- 記事末尾にのみ小さく記載
- 「※」などの記号だけで注記に飛ばす形式

---

## 3. 配置ルール（明瞭性の要件）

**表示があっても、消費者が認識できなければ不十分と判断されうる。** 以下を満たすこと。

- [ ] **記事本文の冒頭**、タイトル直下に配置
- [ ] **ファーストビュー内**に入る（PC・スマホ両方で確認。スマホで画像や目次に押し出されていないか要検証）
- [ ] 本文と同等以上の文字サイズ
- [ ] 背景とのコントラストを確保（薄いグレー文字は不可）
- [ ] 折りたたみ・アコーディオン内に入れない
- [ ] 別ページへのリンクで済ませない
- [ ] 他の注記や広告に紛れない位置に置く

**判定基準**：スマホでページを開いた瞬間、スクロールせずに読めるか。読めないなら不十分。

## 4. 実装（WordPress）

### PHP：テーマの `functions.php` または子テーマに追加

```php
/**
 * 全投稿の本文冒頭に広告表示を自動挿入する（ステマ規制対応）
 * 優先度 1 で早期に実行し、他のフィルタより先に付与する
 */
add_filter( 'the_content', 'aff_prepend_ad_disclosure', 1 );
function aff_prepend_ad_disclosure( $content ) {
	// 投稿の単体表示・メインループのみを対象にする
	// （アーカイブや抜粋、ウィジェットでの二重表示を防ぐ）
	if ( ! is_singular( 'post' ) || ! in_the_loop() || ! is_main_query() ) {
		return $content;
	}

	// 個別記事で無効化したい場合はカスタムフィールド aff_no_ad = 1
	// ※広告リンクを含まない記事のみ。含む記事では絶対に外さないこと
	if ( get_post_meta( get_the_ID(), 'aff_no_ad', true ) === '1' ) {
		return $content;
	}

	$notice  = '<div class="ad-disclosure" role="note">';
	$notice .= '<span class="ad-disclosure__label">PR</span>';
	$notice .= '<span class="ad-disclosure__text">本記事には広告（アフィリエイトリンク）が含まれます。</span>';
	$notice .= '</div>';

	return $notice . $content;
}
```

### 静的サイト（Astro等）を選んだ場合

レイアウトコンポーネントに直接埋め込み、記事側から制御できないようにする。

```html
<div class="ad-disclosure" role="note">
  <span class="ad-disclosure__label">PR</span>
  <span class="ad-disclosure__text">本記事には広告（アフィリエイトリンク）が含まれます。</span>
</div>
```

## 5. 実装後の検証

- [ ] 新規記事を1本作り、**何も設定せずに**広告表示が出ることを確認（オプトインではなくデフォルトONであること）
- [ ] スマホ実機でファーストビュー内に入ることを確認
- [ ] AMP・PWA・キャッシュプラグイン経由でも表示されることを確認
- [ ] 目次プラグイン・アイキャッチ画像より**上**に出ることを確認
- [ ] 一覧ページの抜粋に混入していないことを確認

---

## 6. 運用ルール

1. **広告表示は記事側で外せない設計にする。** カスタムフィールドでの無効化は、広告リンクを一切含まない記事にのみ使う
2. **記事レビュー時のチェック項目に含める**（CLAUDE.md ルール9）
3. **各ASP・広告主の掲載ルールを別途確認する。** 案件によって追加の表記要件がある。`data/program-rules.md` の台帳で管理する
4. **消費者庁の運用基準に変更がないか、年1回確認する**
