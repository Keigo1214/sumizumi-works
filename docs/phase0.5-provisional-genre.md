## 4. 推奨案

**仮の候補ジャンル：小さな店舗の「開業・運営のITツール」。中心は POSレジ。ホームページ作成と予約システムを隣接分野にする。**

- 読者：飲食店・美容室・サロン・小売店・アパレル・自費の整体やリラクゼーションなどを営む人、これから開く人
- **扱わないもの**：
  - 決済サービスを単独で比べる記事（手数料の比較など）。決済は POS の記事の中で、費用の項目（手数料・端末代・入金サイクル）としてだけ扱う。「審査の通りやすさ」「入金を早める方法」「資金繰り」は扱わない（金融・YMYL に近いため）
  - **決済だけの案件（Airペイ・PAYGATE・PayCAS など）の申込ボタンは置かない**（決済の審査申込へ送る導線は、扱わないと決めた「審査」に近いため）。STORES のように1つのプログラムに POS と決済の成果地点がある案件は、POS の成果地点に向けて案内する
- **モバイルオーダーは範囲に含める**：飲食店の注文の仕組みとして、POS と一体で扱う（funfo・テイクイーツなど）。単独の型A にするかは Phase 3 の手前で決める
  - 保険診療のある業種（クリニック・歯科・薬局・整骨院・接骨院）。レセコン連携などは保険診療の会計の話で、医療に踏み込むため（CLAUDE.md ルール6）
  - 広告規制のある業種のホームページ（医療・士業・不動産など。法律の説明が要るため）
- 最初の10記事（型A中心）は **POSレジを中心**にする（具体的なキーワードは Phase 3 の手前で決める）。ジャンルを変えても資産として残る型A にする（STRATEGY Phase 0.5）

**理由**

1. **ASP の案件の数がいちばん厚い**：A8.net だけで、決済だけの案件を除いても、製品として比べられる広告主が8社、報酬5,000円以上の案件が11件ある（報酬額の表示。確定率を掛けて5,000円を超えると確認できたのは Airレジ1件だけ）。比較の基準の勤怠管理は1件だった
2. **POS・ホームページ・予約は、読者（店舗を営む人・開く人）が同じ**なので、内部リンクでつなぎやすい。3分野をまたいで売るメーカーとして確認できたのは STORES（レジ・予約・ネットショップ）ぐらい（リクルートの Air シリーズはレジ・決済・予約・シフトなどで、ホームページ作成は見当たらない。公式の全製品一覧は未確認）。ホームページ作成で確定率が高いのは自己登録型（ペライチ 100%・エックスサーバー 90%・ジンドゥー 80.76%）で、1件あたりは主に2,000〜3,000円台以下。報酬の高い案件（30,000円〜）は制作代行で確定率の表示がない。POS の資料請求型の弱さ（電話のヒアリングによる否認）を**補えるかは推定**
3. **POS は業種で要る機能がはっきり違う**ので、型B の「業種×課題」が内容の違う記事になりやすい（ただし下の「弱いところ」6・7）
4. **業種を組み合わせた検索の上位に、大手比較メディアは0〜2件**。すでに小規模の比較サイトもいて空き地ではないが、Phase 1 の条件（個人・小規模サイトが3件以上）には好材料（推定。Phase 1 で実測する）

**弱いところ・未確認のこと（隠さずに書く）**

1. **確定率を掛けても5,000円を超えると確認できたのは Airレジ1件だけ**。ほかは確認できたもので1件あたり約1,430〜3,440円
2. **主力が Airレジ1件に集中する**。Airレジがなくなると、確認できている代わりの案件は1件あたり半分以下（約3,300〜3,500円）になる。即時撤退の条件1（STRATEGY Phase 10「主力案件が終了し、代替がない」）に近づく
3. **Airレジは「App Store からの申込」を否認する**。iPad のアプリなので、「記事を読む → App Store で入れる」という自然な流れが否認になるおそれがある。記事の案内の仕方（ウェブのアカウント登録へ案内する）を提携前に確かめる
4. 資料請求型の案件（ポスタス・スマレジなど）は、**電話のヒアリングで店舗の情報を確認できないと否認**になる。実際に店舗を持つ（開く）読者に向けた記事でないと確定しない
5. **料金の公開は POS で7社中4〜5社**。資料請求型の広告主ほど非公開で、網羅性で勝つ型は取りにくい

**採らなかった候補**

- 予約システムを中心にすること：比較の意図のある検索は最も厚いが、A8.net の案件が4社・報酬5,000円以上は1件で、報酬 × 確定率では freee予約（3,000円・100%）が最も高い → 隣接分野として扱う
- ホームページ作成を中心にすること：案件は厚いが、業種で要る機能の違いが POS ほどはっきりせず（推定）、ロングテールの検索結果も未取得。制作会社の業種別ページが多い分野でもある（推定）→ 隣接分野として扱う
- 顧客管理：店舗向けの案件は少なく、多くが POS と重複する
- キャッシュレス決済を単独で扱うこと：本丸の語の上位に金融メディアが並び、決済は YMYL に近い → POS の記事の費用の項目としてだけ扱う
- クラウドPBX・バーチャルオフィス・ネットショップ：業種と組み合わせた検索が少ない
- 勤怠管理：A8.net の関係のある案件が1件（3,800円）。本丸の語の上位は大手比較メディアが7件
