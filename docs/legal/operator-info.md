# 運営者情報・免責事項（固定ページ用テンプレート）

## 設計方針

**個人名ではなく屋号ベースで作成する。** 理由は2つ。

1. **売却可能性の確保**（STRATEGY.md Phase 0-E）— 運営が実行者個人のキャラクターに依存すると、譲渡時に価値が大きく毀損する。「◯◯さんのサイト」ではなく「◯◯という媒体」にしておく
2. プライバシー — 個人の住所・電話番号を開示する義務は、アフィリエイトのみの運営では発生しない

> **ただし Phase 9 で自社ツール等の有料販売を始めた時点で、特定商取引法に基づく表記が必須になり、個人事業主の場合は氏名・住所・電話番号の開示義務が発生する。** その段階で本ページの扱いを見直すこと。

**E-E-A-T の観点では、運営者情報は薄くしすぎない。** 誰が何の目的で運営し、情報をどう検証しているかを具体的に書くことが、実体験を書けない本サイトにとって信頼性の主要な担保になる。

### 運営方針

当サイトは、{{ジャンル}}を検討する方が、**比較検討にかかる時間を短縮できること**を目的としています。

情報の作成にあたっては、以下を方針としています。

1. **一次資料に基づく** — 掲載する料金・仕様・制度に関する情報は、提供元の公式サイト、公的機関の公表資料、企業の開示資料など、確認可能な一次資料をもとに作成しています
2. **出典を明示する** — 数値や制度に関する記述には、参照元のURLと参照日を記載しています。読者が自身で検証できる状態を維持します
3. **更新日を明示する** — 料金や条件は変更されます。各記事に最終更新日を表示しています
4. **広告であることを明示する** — 広告（アフィリエイトリンク）を含む記事には、記事冒頭にその旨を表示しています

### 情報の検証方法

掲載情報は、公開後も定期的に提供元の公式情報と照合し、変更があった場合は更新しています。

記載内容に誤りを発見された場合は、{{連絡先}} よりご指摘ください。確認のうえ、速やかに訂正いたします。

### 収益について

当サイトは、アフィリエイトプログラムおよび広告収益によって運営されています。

**掲載順序や評価は、報酬額によって決定していません。** 掲載基準は各記事に明記しています。

## 免責事項（テンプレート）

### 掲載情報の正確性について

当サイトは、掲載情報の正確性を期して運営していますが、その完全性・最新性・特定目的への適合性を保証するものではありません。

料金、仕様、提供条件、制度の内容等は、予告なく変更される場合があります。**契約・申込みの前に、必ず提供元の公式情報をご確認ください。**

### 損害等の責任

当サイトの情報を利用したことにより生じた、いかなる損害についても責任を負いかねます。

### 外部リンクについて

当サイトから外部サイトへ移動された場合、移動先サイトで提供される情報、サービス、商品について、当サイトは一切の責任を負いません。

### 著作権について

当サイトに掲載されている文章、画像、図表等の著作権は、当サイトまたは正当な権利者に帰属します。引用の範囲を超える無断転載を禁じます。

引用の際は、出典として当該ページのURLを明記してください。
