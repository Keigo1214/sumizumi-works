# 法務コンポーネント（Phase 0-A）

サイト公開前に**必ず全て設置する**もの。記事を書き始めてからでは手戻りが大きい。

| ファイル | 内容 | 優先度 |
|---|---|---|
| `ad-disclosure.md` | 広告表示（ステマ規制対応）。実装コード込み | **最優先** |
| `privacy-policy.md` | プライバシーポリシー本文 | 必須 |
| `operator-info.md` | 運営者情報・免責事項 | 必須 |
| `business-registration.md` | 開業届・青色申告のチェックリスト | 期限あり |

---

## 免責

ここにあるのは**実務上一般的とされる構成に基づくテンプレート**であり、法的助言ではありません。以下の2点は特に注意してください。

1. **広告表示（ステマ規制）は、違反時に事業の根幹が止まる**（ASP経由の提携解除・成果全否認）。テンプレートをそのまま使うのではなく、消費者庁の運用基準の原文と、提携する各ASP・広告主の掲載ルールを必ず確認してください
2. 収益規模が大きくなった段階（目安：年商数百万円）で、一度専門家のレビューを受けることを推奨します

| プレースホルダ | 例 |
|---|---|

| `{{サイト名}}` | ◯◯ナビ |
| `{{ドメイン}}` | example.com |
| `{{連絡先}}` | 問い合わせフォームのURL、またはメールアドレス |
| `{{制定日}}` | 2026年◯月◯日 |
